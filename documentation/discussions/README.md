## How to read each thread

- `00-overview.md` — the question being answered, options on the table, current status.
- `NN-<topic>.md` — one numbered file per substantive sub-topic, in the order they were discussed. Each ends with the conclusion or the open question that fed into the next file.
- `99-decision.md` — the final landing point, once we've reached one.
