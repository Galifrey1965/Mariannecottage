# Discussions

Running record of design discussions where we work through a topic until we have a clear decision (or a clear "parked, here's why"). One subfolder per topic, numbered files within so the thread reads top-to-bottom.

The goal is to make our reasoning legible for the owners (Mark & Kim) — they should be able to skim these and see what was considered and why we landed where we did.

## How to read each thread

- `00-overview.md` — the question being answered, options on the table, current status.
- `NN-<topic>.md` — one numbered file per substantive sub-topic, in the order they were discussed. Each ends with the conclusion or the open question that fed into the next file.
- `99-decision.md` — the final landing point, once we've reached one.
